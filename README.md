# Hackmate API

Laravel API for Hackmate authentication, projects, and recommendation feed generation.

## Requirements

- PHP 8.4+
- Composer
- PostgreSQL (or SQLite for tests)
- Node.js (optional, only if you use frontend build tooling)

## Quick Start

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan jwt:secret
php artisan migrate
php artisan serve
```

If you use Docker DB from this repo:

```bash
docker compose up -d db
php artisan migrate
```

## Environment Variables

Set at minimum:

- `APP_KEY`
- `JWT_SECRET`
- `DB_*` values
- `GITHUB_OAUTH_CLIENT_ID`
- `GITHUB_OAUTH_CLIENT_SECRET`
- `GITHUB_OAUTH_REDIRECT_URI` (example: `http://localhost:8000/api/v1/github/callback`)
- `FRONTEND_GITHUB_CALLBACK_URL` (example: `http://localhost:5173/auth/github/callback`)

## Auth Endpoints

- `POST /api/v1/auth/login`
- `POST /api/v1/auth/refresh` (auth required)
- `POST /api/v1/auth/logout` (auth required)
- `GET /api/v1/auth/me` (auth required)
- `POST /api/v1/auth/forgot-password`
- `POST /api/v1/auth/reset-password`

GitHub OAuth flow:

1. `GET /api/v1/github/login-url`
2. Redirect user to returned URL
3. GitHub calls backend callback
4. Backend redirects to frontend callback with JWT token

## Project and Feed Endpoints

- `GET /api/v1/projects`
  - Auth required
  - Returns active projects ordered by generated feed rank
- `POST /api/v1/projects`
  - Auth required
- `PUT /api/v1/projects/{id}`
  - Auth required, owner only
- `GET /api/v1/feed`
  - Auth required
  - Dedicated feed endpoint using generated ranking

Note: `like_count` and `dislike_count` are stored for recommendation scoring but hidden from API responses.

## Recommendation Feed Generation

Feed ranking is generated by an Artisan command:

```bash
php artisan app:generate-project-recommendations
```

What it does:

- Reads active projects
- Scores each as `like_count - dislike_count`
- Rebuilds `feeds` table with deterministic rank order

### Scheduler

The command is scheduled hourly in `routes/console.php`:

```php
Schedule::command('app:generate-project-recommendations')->hourly();
```

Run scheduler locally:

```bash
php artisan schedule:work
```

Production cron example:

```cron
* * * * * cd /path/to/hackmate-api && php artisan schedule:run >> /dev/null 2>&1
```

## Database Seeding

Run seeders:

```bash
php artisan db:seed
```

`ProjectSeeder` uses `ProjectFactory` to generate projects:

- Creates 10 projects
- If a user exists, assigns projects to that user

## Testing

Run all tests:

```bash
php artisan test
```

Run recommendation-related tests:

```bash
php artisan test tests/Feature/ApiRoutesE2ETest.php tests/Feature/GenerateProjectRecommendationsCommandTest.php
```
